FlowVoice

AI 语音听写，适用于 Windows 上的任何应用。干净、带标点、语气得当。免费、开源，愿意的话也能 100% 离线使用。

下载 Windows 版 GitHub

Windows 10 和 11 · ~3 MB · 无需管理员权限

边说边看到文字。

实时显示，不会倒退
尚不确定的词显示得更浅，两次结果一致后才会确定。已确定的内容不会再变。
一键重做
在结果上可以切换风格、翻译、粘贴或复制。如果已经粘贴，替换会就地换掉文字。
想放哪就放哪（2.2 新功能）
录音时，可以把胶囊拖到屏幕任意角落，甚至另一台显示器上。也可以在 常规 → 浮动窗口 中选一个专属位置。
玻璃效果（2.1 新功能）
胶囊可以是玻璃效果，使用 Windows 自带的模糊，也可以是半透明。在 常规 → 浮动窗口 中设置。

说一次，每个地方都用对的语气。

选择风格，或者让当前应用替你选。

“嗯，大家好，那个，关于季度报告，就是，我需要每个人在周五，嗯，中午之前把自己的部分发给我，这样我能在周一开会前全部看一遍”

大家好。关于季度报告：请各位在周五中午12点前提交各自负责的部分，以便我在周一会议前完成审阅。

正式、有条理，可直接用于邮件。

强度

按应用设置风格

FlowVoice 能识别当前聚焦的应用（包括浏览器中的网页应用），并使用你为它设置的风格。

在 Chrome 和 Edge 中，Gmail、WhatsApp Web、ChatGPT 等也能被识别。

选中文字，说出要改什么。

在命令模式下，Ctrl Alt K 会就地改写选中的文字，适用于任何应用。

  1. 已选中

    李娜，明天的会我去不了了，这边出了点状况，不好意思哈

  2. 你说

    “改得正式一点”

  3. 结果

    李娜，你好。很抱歉，因临时有事，我无法参加明天的会议，敬请谅解。

也可以说“翻译成英文”“总结成要点”“改正语法”。只想改对拼写？选中后按 Ctrl Alt J：校对会修正重音和标点，不改动用词，也不用开口。

真正免费，没网也能用。

用免费密钥
Groq（推荐）、Gemini、Mistral 或 OpenRouter。无需银行卡，几分钟搞定。查看密钥指南
或者 100% 在你的电脑上
本地 Whisper 模型，其中还有一个专为巴西葡萄牙语优化的模型。任何内容都不会离开你的电脑。
无需账号，没有我们的服务器
密钥保存在 Windows 凭据库中。开源，采用 GPL-3.0 许可证。隐私

还有那些用得上的细节。

  • 边听写边翻译说中文，粘贴为 34 种语言中的任意一种。Ctrl Shift Y
  • 自己的词汇人名、品牌和专业术语总能写对。
  • 可搜索的历史记录你听写过的所有内容都保存在你的电脑上。
  • 按住说话只在按住快捷键时录音。
  • 语音助手大声提问，联网搜索后回答。Ctrl Shift U
  • 自动更新~3 MB 的安装程序，无需管理员权限。
  • 重试转写失败时，录音会留在内存中，一键就能重新听写。
  • 录音时静音可选：录音期间电脑静音，结束后自动恢复。
  • 支持 10 种语言葡萄牙语、英语、西班牙语、法语、德语、日语、中文、俄语、印地语和孟加拉语。

常见问题

真的免费吗？

是的。FlowVoice 没有服务器：它用你的密钥直接连接服务商，或者在你的电脑上运行。Groq 和 Gemini 的免费套餐足够日常使用，无需银行卡。

安装时 Windows 弹出了警告。安全吗？

这是正常的：安装程序还没有付费签名。点击“更多信息”，再点“仍要运行”。安装程序由 GitHub Actions 从开源代码构建。

支持哪些系统？

Windows 10 和 11。安装程序约 3 MB，无需管理员权限，并会自动更新。

发现问题或有想法，去哪里反馈？

在 GitHub 上：报告问题或提出改进建议。在应用的 设置 → 关于 中，同样的按钮会自动填好应用和 Windows 的版本。
