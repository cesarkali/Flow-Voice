Free keys in a few minutes

FlowVoice charges nothing and has no server of its own: it talks directly to the AI provider you choose. All it takes is a free API key. Or none, if you prefer to use it offline.

The fastest way

If you only want to dictate today: create a key at Groq and you're done. It transcribes your voice and polishes the text, it is very fast, and the free plan covers a whole day of normal use.

The other keys are optional. Having more than one provider works as a backup: if one fails or hits its limit, FlowVoice moves on to the next on its own.

No need to memorize anythingInside the app, each provider has this same step-by-step, a button that opens the right page and a Test button that confirms the key works.

Providers, step by step

Each one takes a few minutes. Start with Groq; the others serve as backup or add features.

Groq

RecommendedFree

Voice and text. Very fast transcription and polishing.

  1. Open the Groq console and sign in with Google, GitHub or email.
  2. In API Keys, click Create API Key and give it any name, like “FlowVoice”.
  3. Copy the key (it starts with gsk_). It is shown only once.
  4. Paste it into FlowVoice and click Test.
Open console.groq.com Free plan: hours of audio per day, no card.

Google Gemini

Free

Voice and text. Google's AI, with a generous free plan.

  1. Open Google AI Studio and sign in with your Google account.
  2. Click Create API key.
  3. Choose an existing project or create a new one.
  4. Copy the key (it starts with AIza) and paste it into the app.
Open aistudio.google.com On the free plan, Google may use what you send to improve its products.

OpenRouter

:free models

Text only: polishing, translation and questions. Gives access to dozens of models, and the ones ending in :free cost nothing.

  1. Open OpenRouter and sign in with Google, GitHub or email.
  2. Click Create Key and give it a name. The credit limit is optional.
  3. Copy the key (it starts with sk-or-) and paste it into the app.
Open openrouter.ai With no credits on the account: about 50 requests per day on the free models.

Mistral

No card

Voice and text. European AI, with a very good transcription model.

  1. Open the Mistral console and create your account.
  2. Choose the free plan (Experiment). It doesn't ask for a card.
  3. In API Keys, create a new key.
  4. Copy the key and paste it into the app.
Open console.mistral.ai

Tavily

Web search

Optional. Gives the voice assistant (Ctrl Shift U) access to the internet: it searches and answers, citing its sources.

  1. Open Tavily and create your account.
  2. The key (it starts with tvly-) already shows up on the dashboard.
  3. Copy it and paste it into the app.
Open app.tavily.com Free plan: 1,000 credits per month, no card.

Pasting the key in the app

  • The first time, the setup wizard asks for the key. After that, it lives in Settings → Providers.
  • Click Test. If something goes wrong, the app shows the provider's real message, not an “unknown error”.
  • The order of the providers is the order they are tried in. Drag to change it.

Where the key is stored

In the Windows Credential Manager. Only in rare cases, when the vault is unavailable or rejects a very long key, it goes into a local file in your user folder. It only leaves your PC to go to the provider itself, with each request.

More than one key

You can add several keys for the same provider. When one hits its limit or fails, FlowVoice moves to the next one automatically.

And when a model is retired?

Providers swap models often. FlowVoice notices when a model goes offline, picks a replacement from the provider's current list, tests it and starts using it on its own. It also checks this once a day, in the background. You don't have to touch anything.

Free plan limits, plainly

Every free plan has a ceiling: so many requests per minute, so many minutes of audio per day. For everyday dictation, it's plenty. The exact numbers change from time to time, so check each provider's page.

How each provider's free limit is counted
ProviderThe limit applies toAnother key on the same account
GroqThe whole account (organization)Doesn't raise the quota
GeminiThe Google project, not the keyDoesn't raise it, if it's in the same project
OpenRouterRequests per day on :free models; goes up if the account has purchased creditsDoesn't raise it
TavilyCredits per month; each search costs 1 or 2Doesn't raise it

Several keys on the same account don't add upOn Groq, the limit applies to the whole account: five keys on the same account give exactly the same quota as one. What really helps is having different providers as backup, for example Groq and Gemini.

Without internet: 100% offline

Prefer not to use any cloud? In Settings → Transcription, choose 100% local and download a speech recognition model (Whisper). Transcription runs on your processor and the audio never leaves your PC.

The app shows which models are recommended for the language you speak. The numbers below are approximate:

Offline models: size, memory and who they suit
ModelDownloadMemory in useBest for
Tiny31 MB~150 MBVery weak PCs; makes more mistakes
Base57 MB~300 MBFast; also used for the live preview
Small181 MB~600 MBGood balance for the most widely spoken languages
Distil-Whisper pt-BR pt-BR513 MB~950 MBTuned for Brazilian Portuguese
Large v3 Turbo547 MB~1 GBMaximum accuracy in any language
  • To be honest: offline is slower than the cloud, especially with the large models on modest PCs. Local mode needs a processor with AVX2 (most from the last ten years have it; if yours doesn't, the app tells you).
  • The model only takes up memory while you dictate and is released a few seconds later.
  • Each model is downloaded once, only when you ask, and can be deleted at any time on the same screen.
  • To polish text without internet too, use Ollama, which runs a text AI on your PC.
