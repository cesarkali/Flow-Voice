入手

話すだけで、文字がカーソルの位置に。

FlowVoice

Windows のどのアプリでも使える AI 音声入力。句読点まで整い、場面に合った文章になります。無料でオープンソース。望むなら 100% オフラインでも使えます。

Windows 版をダウンロード GitHub

Windows 10・11 · ~3 MB · 管理者権限は不要

話しながら文字が見えます。

リアルタイムで、後戻りなし
まだ確定していない言葉は薄く表示され、2 回続けて同じ結果になると確定します。確定した部分はもう変わりません。
ワンクリックでやり直し
結果が出たら、スタイルの変更、翻訳、貼り付け、コピーができます。貼り付けた後でも、置き換えでその場の文章を差し替えられます。
好きな場所に（2.2 の新機能）
録音中にカプセルを画面のどこへでもドラッグできます。別のモニターにも移せます。決まった位置を選ぶなら、一般 → フローティングウィンドウで。
ガラス（2.1 の新機能）
カプセルは、Windows 自体のぼかしを使ったガラスか、半透明にできます。一般 → フローティングウィンドウで設定します。

話すのは一度。文章は場所ごとにふさわしく。

スタイルを選ぶか、使っているアプリに任せましょう。

話した内容Outlook で

「えっと、みなさん、あの、四半期レポートの件なんですけど、なんか、各自の担当分を金曜の、えー、お昼までに送ってもらえますか。月曜の会議の前に全部確認したいので」

みなさん、お疲れさまです。四半期レポートの件ですが、各自の担当分を金曜日の正午までにお送りください。月曜日の会議の前にすべて確認したいと思います。

フォーマルで整った文章に。そのままメールに使えます。

強さ

アプリごとのスタイル

FlowVoice は使っているアプリをブラウザー内も含めて認識し、そのアプリに設定したスタイルを使います。

Gmail、WhatsApp Web、ChatGPT なども、Chrome や Edge の中で認識されます。

文章を選んで、変えたいことを言うだけ。

コマンドモードでは、Ctrl Alt K で選択した文章をその場で書き直します。どのアプリでも使えます。

  1. 選択した文章

    美咲さん、明日の会議やっぱ行けないわ、ちょっとトラブっちゃって、ごめん

  2. 話す内容

    「もっと丁寧にして」

  3. 結果

    美咲さん、申し訳ありませんが、急な事情により明日の会議に出席できなくなりました。ご迷惑をおかけしてすみません。

「英語に翻訳して」「箇条書きでまとめて」「文法を直して」なども使えます。

本当に無料。ネットがなくても使えます。

無料のキーで
Groq（おすすめ）、Gemini、Mistral、OpenRouter。カード不要で、数分で用意できます。キーの取得ガイドを見る
または 100% PC の中で
ローカルの Whisper モデル。ブラジル・ポルトガル語向けに調整したモデルもあります。データは PC の外に一切出ません。
アカウント不要、私たちのサーバーもなし
キーは Windows の資格情報ストアに保存されます。オープンソースで、ライセンスは GPL-3.0 です。プライバシー

あると助かる細かな機能も。

  • 音声入力しながら翻訳日本語で話して、34 言語のどれかで貼り付け。Ctrl Shift Y
  • 自分だけの語彙名前、ブランド名、専門用語をいつも正しく書きます。
  • 検索できる履歴音声入力した内容はすべて PC に保存されます。
  • 押している間だけ録音ショートカットを押している間だけ録音します。
  • 音声アシスタント声で質問すると、Web で調べて答えます。Ctrl Shift U
  • 自動でアップデート~3 MB のインストーラー。管理者権限は不要です。
  • もう一度試す文字起こしに失敗しても録音はメモリに残り、ワンクリックで音声入力をやり直せます。
  • 録音中は消音オプション：録音中は PC の音をミュートし、終わると自動で戻します。
  • 10 言語に対応ポルトガル語、英語、スペイン語、フランス語、ドイツ語、日本語、中国語、ロシア語、ヒンディー語、ベンガル語。

よくある質問

本当に無料ですか？

はい。FlowVoice にはサーバーがありません。あなたのキーでプロバイダーに直接つなぐか、PC の中で動かします。Groq と Gemini の無料プランで、普段の使い方なら十分です。カードも不要です。

インストール時に Windows の警告が出ました。安全ですか？

想定どおりの表示です。インストーラーにはまだ有料の署名がありません。「詳細情報」をクリックし、「実行」を選んでください。インストーラーは公開されたソースコードから GitHub Actions で作られています。

どの OS で動きますか？

Windows 10 と 11 です。インストーラーは約 3 MB で、管理者権限は不要、アップデートも自動です。

問題を見つけた、アイデアがある。どこに伝えればいいですか？

GitHub で問題を報告するか、改善を提案してください。アプリの設定 → 情報にある同じボタンを使うと、アプリと Windows のバージョンが自動で入ります。

ブラジルの個人が、オープンに作っています。

FlowVoice は無料で、これからもずっと無料です。時間の節約になっていたら、LivePix（Pix、ブラジル向け）か GitHub Sponsors（各種カード、毎月または 1 回）でコーヒー 1 杯分の支援をいただけると、アップデートを続けられます。
