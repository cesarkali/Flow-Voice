入手

あなたの声はあなたのもの。

FlowVoice にはサーバーがなく、アカウントも求めず、あなたについて何も収集しません。このページでは、何がどこへ行くのかを、法律用語なしで説明します。

概要

音声はメモリの中だけ
録音がディスクに保存されることはありません。音声は選んだプロバイダーにだけ送られ、オフラインモードならどこにも送られません。文字起こしが失敗した場合は、やり直せるように録音がメモリに残ります。
キーはシステムの資格情報ストアに
Windows 資格情報マネージャーに保存されます。まれな場合にだけローカルファイルに保存されます（下記参照）。
履歴は PC の中だけ
いつでもオフにしたり削除したりできます。
テレメトリーなし
アプリにはアクセス解析も、トラッキングも、利用状況の送信もありません。

あなたの声と文章

音声入力の間、マイクの音声はプログラムのメモリの中だけにあります。ファイルに保存されることはなく、音声入力が終わると破棄されます。

唯一の例外：文字起こしが失敗した場合（インターネットなし、プランの上限、無効なキー）、もう一度試すボタンのために録音がメモリに残ります。残るのは直近 3 件の失敗までです。これもディスクには保存されず、履歴からその項目を削除したとき、履歴を消去したとき、または FlowVoice を終了したときに消えます。

クラウドの場合

クラウドのプロバイダー（Groq、Google Gemini、Mistral、OpenAI、OpenRouter、または独自のアドレス）を使う場合、FlowVoice はあなたのキーを使ってそのプロバイダーに直接送ります：

  • 音声（文字にするため）
  • 文字起こしされた文章と、選んだスタイルの指示、あなたの語彙、音声入力しているアプリの名前（場面に合った文章にするため）
  • コマンドモードでは、選択した文章
  • 音声アシスタントでは、質問と会話。Tavily のキーがあれば、Web 検索のため質問が Tavily にも送られます。

途中に FlowVoice のサーバーはありません。各プロバイダーがそのデータをどう扱うかは、それぞれのポリシーに従います。

知っておいてくださいGoogle Gemini の無料プランでは、Google が送信内容を自社製品の改善に使う場合があります。気になる場合は、別のプロバイダーかオフラインモードを選んでください。

オフラインの場合

100% ローカルモードでは、文字起こしはあなたのプロセッサー上で動きます。文章の整形に Ollama を使えば、話した内容は何ひとつコンピューターの外に出ません。

API キー

キーは Windows 資格情報マネージャーに保存されます。PC の外に出るのは、リクエストのたびにそのプロバイダーへ送るときだけで、画面上では伏せ字で表示されます。

まれな例外：資格情報ストアが使えない、または長すぎるキーを受け付けない場合、キーはあなたのユーザーフォルダー内にあるアプリの設定フォルダーのファイルに保存されます。

PC に保存されるもの

  • 音声入力の履歴（文章、スタイル、入力先のアプリ）。直近 300 件まで。設定 → 一般 → 履歴を残すでオフにでき、ホーム画面で 1 件ずつ削除することも、すべて消去することもできます。
  • 設定、スタイル、語彙。
  • ダウンロードしたオフラインモデル。モデルの画面でいつでも削除できます。
  • 問題を診断するための技術ログ。記録するのは技術的なイベント（時刻、エラー、応答時間）だけで、音声入力した内容は記録しません。サイズは約 1 MB までで（超えると作り直されます）、どこにも送信されません。PC の外に出るのは、あなた自身がバグ報告に添付したときだけです。

すべて Windows のあなたのユーザーフォルダー内にあります：

FlowVoice が Windows でデータを保存するフォルダー
フォルダー保存内容
%APPDATA%\br.com.caliberda.flowvoice設定、履歴、ログ
%LOCALAPPDATA%\br.com.caliberda.flowvoiceオフラインモデル

すべてを一度に消すには、これらのフォルダーを削除するだけです。

アプリが行うその他の接続

設定したプロバイダーのほかに、FlowVoice がインターネットに接続するのは次の場合だけです：

  • GitHub でアップデートを確認。アップデートにはデジタル署名があります。
  • Hugging Face からオフラインモデルをダウンロード。あなたが求めたときだけです。
  • 情報画面に作者の写真を表示。GitHub から取得し、オフライン用に保存します。
  • プロバイダーのモデル一覧を確認し、廃止されたモデルを自動で切り替えます。

これらの接続で、あなたの声、文章、履歴が送られることはありません。

テレメトリー：なし

アプリにはアクセス解析、トラッキング、ユーザー ID、エラーの自動送信がありません。何人がどう使っているのか、私たちにもわかりません。コードは公開されているので、誰でも GitHub のリポジトリで確かめられます。

このサイト

このサイトは静的サイトで、Vercel でホストしています。ほかのサーバーと同じく、Vercel はページの配信と不正利用の防止のため、訪問の技術データ（IP アドレスやブラウザーなど）をVercel のプライバシーポリシーに従って記録します。

このサイトにはアクセス解析、Cookie、トラッキング用スクリプトがありません。文字のフォントは Google Fonts から読み込むため、Google Fonts はほかのサーバーと同じようにそのダウンロードのリクエストを受け取ります。

フォーム、ログイン、広告はありません。インストーラーは GitHub から直接ダウンロードされます。
