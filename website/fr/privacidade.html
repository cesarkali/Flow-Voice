Obtenir

Votre voix est à vous.

FlowVoice n'a pas de serveur, ne demande pas de compte et ne collecte rien sur vous. Cette page explique, sans jargon juridique, où va chaque chose.

Résumé

L'audio reste en mémoire
Aucun enregistrement n'est sauvegardé sur le disque. L'audio part uniquement vers le fournisseur que vous avez choisi, ou nulle part en mode hors ligne. Si la transcription échoue, l'enregistrement reste en mémoire uniquement pour que vous puissiez réessayer.
Clés dans le coffre du système
Conservées dans le Gestionnaire d'informations d'identification de Windows ; dans de rares cas seulement, elles se trouvent dans un fichier local (voir plus bas).
Historique uniquement sur votre PC
Peut être désactivé ou effacé quand vous voulez.
Zéro télémétrie
L'application n'a ni analyse d'audience, ni suivi, ni rapport d'utilisation.

Votre voix et votre texte

Pendant que vous dictez, l'audio du microphone reste uniquement dans la mémoire du programme. Il n'est jamais écrit dans un fichier et il est supprimé à la fin de la dictée.

La seule exception : si la transcription échoue (pas d'internet, limite de l'offre, clé invalide), l'enregistrement reste en mémoire pour le bouton Réessayer, au maximum les 3 derniers échecs. Il ne va jamais non plus sur le disque : il disparaît quand vous supprimez l'élément de l'historique, effacez l'historique ou fermez FlowVoice.

Dans le cloud

Si vous utilisez un fournisseur dans le cloud (Groq, Google Gemini, Mistral, OpenAI, OpenRouter ou une adresse personnelle), FlowVoice envoie directement chez lui, avec votre clé :

  • l'audio, pour qu'il devienne du texte ;
  • le texte transcrit, avec les instructions du style choisi, votre vocabulaire et le nom de l'application dans laquelle vous dictez (pour que le texte soit dans le bon ton) ;
  • en mode Commande, le texte que vous avez sélectionné ;
  • dans l'assistant vocal, la question et la conversation. Avec une clé Tavily, la question part aussi chez Tavily, pour chercher sur le web.

Il n'y a aucun serveur FlowVoice entre les deux. Ce que chaque fournisseur fait de ces données relève de sa propre politique.

Bon à savoirAvec l'offre gratuite de Google Gemini, Google peut utiliser ce que vous envoyez pour améliorer ses produits. Si cela vous gêne, préférez un autre fournisseur ou le mode hors ligne.

Hors ligne

En mode 100 % local, la transcription s'exécute sur votre processeur. Avec Ollama pour affiner le texte, rien de ce que vous dites ne quitte votre ordinateur.

Clés d'API

Les clés restent dans le Gestionnaire d'informations d'identification de Windows. Elles ne quittent le PC que pour aller chez le fournisseur lui-même, à chaque requête, et s'affichent masquées à l'écran.

Exception rare : si le coffre n'est pas disponible ou refuse une clé trop longue, elle est placée dans un fichier du dossier de configuration de l'application, dans votre profil utilisateur.

Ce qui est enregistré sur votre PC

  • Historique des dictées (texte, style et application cible), jusqu'aux 300 plus récentes. Désactivez-le dans Paramètres → Général → Conserver l'historique, supprimez les éléments un par un ou effacez tout depuis l'écran Accueil.
  • Paramètres, styles et vocabulaire.
  • Modèles hors ligne que vous avez téléchargés. Supprimez-les quand vous voulez sur l'écran des modèles.
  • Un journal technique pour diagnostiquer les problèmes. Il n'enregistre que des événements techniques (heures, erreurs, temps de réponse), jamais ce que vous avez dicté. Il est limité à environ 1 MB (il est recréé quand il dépasse) et n'est jamais envoyé nulle part : il ne quitte le PC que si vous le joignez vous-même à un rapport de bogue.

Tout reste dans votre profil utilisateur Windows :

Dossiers où FlowVoice conserve des données sous Windows
DossierCe qu'il contient
%APPDATA%\br.com.caliberda.flowvoiceParamètres, historique et journal
%LOCALAPPDATA%\br.com.caliberda.flowvoiceModèles hors ligne

Pour tout effacer d'un coup, il suffit de supprimer ces dossiers.

Autres connexions de l'application

Outre les fournisseurs que vous avez configurés, FlowVoice n'accède à internet que pour :

  • Rechercher des mises à jour sur GitHub. Les mises à jour sont signées numériquement.
  • Télécharger des modèles hors ligne depuis Hugging Face, uniquement quand vous le demandez.
  • Afficher la photo de l'auteur dans l'écran À propos, récupérée sur GitHub et conservée pour un usage hors ligne.
  • Consulter la liste des modèles de vos fournisseurs, pour remplacer automatiquement un modèle retiré.

Aucune de ces connexions ne transporte votre voix, votre texte ou votre historique.

Télémétrie : aucune

L'application n'a ni analyse d'audience, ni suivi, ni identifiant d'utilisateur, ni envoi automatique d'erreurs. Nous ne savons pas combien de personnes l'utilisent, ni comment. Le code est ouvert : tout le monde peut le vérifier dans le dépôt GitHub.

Ce site

Ce site est statique et hébergé chez Vercel. Comme tout serveur, Vercel enregistre des données techniques sur les visites (comme l'adresse IP et le navigateur) pour servir les pages et protéger contre les abus, conformément à sa politique de confidentialité.

Le site n'a ni analyse d'audience, ni cookies, ni scripts de suivi. La police du texte vient de Google Fonts, qui reçoit la demande de téléchargement comme n'importe quel serveur.

Il n'y a ni formulaires, ni connexion, ni publicités. Le programme d'installation est téléchargé directement depuis GitHub.
