几分钟拿到免费密钥

FlowVoice 完全免费，也没有自己的服务器：它直接与你选择的 AI 服务商通信。为此只需要一个免费的 API 密钥。如果你想离线使用，连密钥都不用。

最快的方法

如果你今天就想听写：在 Groq 创建一个密钥就够了。它既能转写语音也能润色文字，速度很快，免费套餐足够一整天的正常使用。

其他密钥都是可选的。多一个服务商就多一份备用：一个失败或达到上限时，FlowVoice 会自动换下一个。

不用死记在应用中，每个服务商都有同样的分步说明，一个打开正确页面的按钮，以及一个确认密钥是否可用的测试按钮。

各服务商分步说明

每个只需几分钟。先从 Groq 开始；其他的可作为备用或增加功能。

Groq

推荐免费

语音和文字。转写和润色都非常快。

  1. 打开 Groq 控制台，用 Google、GitHub 或邮箱登录。
  2. 在 API Keys 中点击 Create API Key，随便起个名字，比如“FlowVoice”。
  3. 复制密钥（以 gsk_ 开头）。它只显示一次。
  4. 粘贴到 FlowVoice 中，点击测试。
打开 console.groq.com 免费套餐：每天数小时音频，无需银行卡。

Google Gemini

免费

语音和文字。Google 的 AI，免费额度很充足。

  1. 打开 Google AI Studio，用你的 Google 账号登录。
  2. 点击 Create API key。
  3. 选择一个现有项目，或新建一个。
  4. 复制密钥（以 AIza 开头），粘贴到应用中。
打开 aistudio.google.com 在免费套餐中，Google 可能会使用你发送的内容来改进其产品。

OpenRouter

:free 模型

仅文字：润色、翻译和提问。可使用数十个模型，名称以 :free 结尾的模型不收费。

  1. 打开 OpenRouter，用 Google、GitHub 或邮箱登录。
  2. 点击 Create Key 并起个名字。额度上限可不填。
  3. 复制密钥（以 sk-or- 开头），粘贴到应用中。
打开 openrouter.ai 账户中没有额度时：免费模型每天约 50 次请求。

Mistral

无需银行卡

语音和文字。欧洲的 AI，转写模型非常好。

  1. 打开 Mistral 控制台，创建账号。
  2. 选择免费套餐（Experiment），无需银行卡。
  3. 在 API Keys 中新建一个密钥。
  4. 复制密钥，粘贴到应用中。
打开 console.mistral.ai

Tavily

网页搜索

可选。让语音助手（Ctrl Shift U）能够上网：它会搜索并在回答中注明来源。

  1. 打开 Tavily，创建账号。
  2. 密钥（以 tvly- 开头）已经显示在控制面板上。
  3. 复制并粘贴到应用中。
打开 app.tavily.com 免费套餐：每月 1000 积分，无需银行卡。

把密钥粘贴到应用中

  • 首次使用时，设置向导会请你输入密钥。之后，它在设置 → 服务商中。
  • 点击测试。如果出了问题，应用会显示服务商返回的真实信息，而不是“未知错误”。
  • 服务商的排列顺序就是尝试的顺序。拖动即可调整。

密钥存放在哪里

在 Windows 凭据管理器中。只有在极少数情况下，比如凭据库不可用或拒绝过长的密钥时，它才会保存在你用户文件夹中的一个本地文件里。它只会在每次请求时发送给对应的服务商，不会以其他方式离开你的电脑。

多个密钥

同一个服务商可以添加多个密钥。一个达到上限或失败时，FlowVoice 会自动换用下一个。

模型下线了怎么办？

服务商经常更换模型。FlowVoice 发现某个模型下线后，会从服务商当前的列表中选一个替代模型，测试后自动改用它。它还会每天在后台检查一次。你什么都不用做。

免费套餐的限制，直说

每个免费套餐都有上限：每分钟多少次请求，每天多少分钟音频。日常听写绰绰有余。具体数字会不时变化，请以各服务商的页面为准。

各服务商免费额度的计算方式
服务商限制针对同一账号再建一个密钥
Groq整个账号（组织）不增加额度
GeminiGoogle 项目，而不是密钥同一项目则不增加
OpenRouter:free 模型每天的请求数；账户有已购额度时会提高不增加
Tavily按月计算的积分；每次搜索消耗 1 或 2 个不增加

同一账号的多个密钥不会叠加在 Groq，限制针对整个账号：同一账号下五个密钥的额度和一个完全一样。真正有用的是用不同的服务商互为备用，比如 Groq 和 Gemini。

不联网：100% 离线

完全不想用云端？在设置 → 转写中选择100% 本地，并下载一个语音识别模型（Whisper）。转写在你的处理器上运行，音频永远不会离开电脑。

应用会显示适合你所说语言的推荐模型。下面的数字仅供参考：

离线模型：大小、内存和适用场景
模型下载大小内存占用适合谁
Tiny31 MB~150 MB配置很低的电脑；错误较多
Base57 MB~300 MB速度快；也用于实时预览
Small181 MB~600 MB常用语言中表现均衡
Distil-Whisper pt-BR pt-BR513 MB~950 MB针对巴西葡萄牙语优化
Large v3 Turbo547 MB~1 GB任何语言都有最高的准确度
  • 说实话：离线比云端慢，尤其是在配置一般的电脑上使用大模型时。本地模式需要支持 AVX2 的处理器（近十年的大多数处理器都支持；如果你的不支持，应用会提示）。
  • 模型只在你听写时占用内存，几秒后就会释放。
  • 每个模型只在你需要时下载一次，并且可以在同一页面随时删除。
  • 如果想在不联网时也能润色文字，可以使用 Ollama，它能在你的电脑上运行文字 AI。
