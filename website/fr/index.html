FlowVoice

Dictée vocale par IA dans n'importe quelle application Windows. Propre, ponctuée et dans le bon ton. Gratuite, open source et, si vous le voulez, 100 % hors ligne.

Windows 10 et 11 · ~3 MB · sans droits d'administrateur

Vous voyez le texte pendant que vous parlez.

En direct, sans retour en arrière
Les mots encore incertains s'affichent plus clairs et se fixent quand deux réponses concordent. Ce qui est fixé ne change plus.
Un clic pour refaire
Sur le résultat, changez de style, traduisez, collez ou copiez. Si vous avez déjà collé, Remplacer change le texte sur place.
Où vous voulez, nouveau dans la 2.2
Pendant l'enregistrement, faites glisser la capsule vers n'importe quel coin, même vers un autre écran. Ou choisissez votre propre position dans Général → Fenêtre flottante.
Verre, nouveau dans la 2.1
La capsule peut être en verre, avec le flou de Windows lui-même, ou translucide. Dans Général → Fenêtre flottante.

Intensité

Un style par application

FlowVoice reconnaît l'application active, même dans le navigateur, et utilise le style que vous lui avez défini.

Gmail, WhatsApp Web, ChatGPT et d'autres sont aussi reconnus dans Chrome et Edge.

Sélectionnez un texte. Dites quoi changer.

En mode Commande, Ctrl Alt K réécrit la sélection sur place, dans n'importe quelle application.

  1. Sélectionné

    salut camille, je pourrai pas venir à la réunion demain, j'ai un souci, pardon

  2. Vous dites

    « rends ça plus formel »

  3. Résultat

    Bonjour Camille. Malheureusement, je ne pourrai pas assister à la réunion de demain en raison d'un imprévu. Toutes mes excuses.

Cela marche aussi avec « traduis en anglais », « résume en puces », « corrige la grammaire ». Juste l'orthographe ? Sélectionnez et appuyez sur Ctrl Alt J : Corriger rectifie les accents et la ponctuation sans changer les mots, et sans que vous ayez à parler.

Questions rapides

C'est vraiment gratuit ?

Oui. FlowVoice n'a pas de serveur : il utilise votre clé directement auprès du fournisseur, ou fonctionne sur votre PC. Les offres gratuites de Groq et de Gemini suffisent pour un usage quotidien normal, sans carte bancaire.

Windows a affiché un avertissement à l'installation. C'est sûr ?

C'est normal : le programme d'installation n'a pas encore de signature payante. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ». Il est généré par GitHub Actions à partir du code ouvert.

Sur quels systèmes ça marche ?

Sur Windows 10 et 11. Le programme d'installation fait environ 3 MB, ne demande pas de droits d'administrateur et se met à jour tout seul.

J'ai trouvé un problème ou j'ai une idée. Où le dire ?

Sur GitHub : signaler un problème ou suggérer une amélioration. Dans l'application, sous Paramètres → À propos, les mêmes boutons remplissent déjà les versions de l'application et de Windows.
