無料のキーを数分で

FlowVoice は無料で、独自のサーバーも持ちません。あなたが選んだ AI プロバイダーと直接やり取りします。必要なのは無料の API キーだけ。オフラインで使うなら、キーも要りません。

いちばん早い方法

今日すぐ音声入力したいなら、Groq でキーを作るだけで準備完了です。音声の文字起こしも文章の整形もこなし、とても速く、無料プランで普段の 1 日分は十分まかなえます。

ほかのキーは任意です。複数のプロバイダーがあると予備になります。どれかが失敗したり上限に達したりすると、FlowVoice が自動で次に切り替えます。

覚えておく必要はありませんアプリ内でも、プロバイダーごとに同じ手順が表示されます。正しいページを開くボタンと、キーが使えるか確かめるテストボタンもあります。

プロバイダー別の手順

どれも数分で終わります。まずは Groq から。ほかは予備になったり、機能を増やしたりします。

Groq

おすすめ無料

音声と文章。文字起こしも整形もとても速い。

  1. Groq のコンソールを開き、Google、GitHub、またはメールでログインします。
  2. API Keys で Create API Key をクリックし、「FlowVoice」など好きな名前を付けます。
  3. キー（gsk_ で始まります）をコピーします。表示されるのは一度だけです。
  4. FlowVoice に貼り付けてテストをクリックします。
console.groq.com を開く 無料プラン：1 日あたり数時間分の音声、カード不要。

Google Gemini

無料

音声と文章。無料枠がたっぷりある Google の AI。

  1. Google AI Studio を開き、Google アカウントでログインします。
  2. Create API key をクリックします。
  3. 既存のプロジェクトを選ぶか、新しく作ります。
  4. キー（AIza で始まります）をコピーしてアプリに貼り付けます。
aistudio.google.com を開く 無料プランでは、Google が送信内容を自社製品の改善に使う場合があります。

OpenRouter

:free モデル

文章のみ：整形、翻訳、質問。数十のモデルが使え、名前が :free で終わるモデルは無料です。

  1. OpenRouter を開き、Google、GitHub、またはメールでログインします。
  2. Create Key をクリックして名前を付けます。クレジットの上限は任意です。
  3. キー（sk-or- で始まります）をコピーしてアプリに貼り付けます。
openrouter.ai を開く アカウントにクレジットがない場合：無料モデルで1 日あたり約 50 リクエスト。

Mistral

カード不要

音声と文章。文字起こしモデルがとても優秀な欧州の AI。

  1. Mistral のコンソールを開き、アカウントを作ります。
  2. 無料プラン（Experiment）を選びます。カードは不要です。
  3. API Keys で新しいキーを作ります。
  4. キーをコピーしてアプリに貼り付けます。
console.mistral.ai を開く

Tavily

Web 検索

任意。音声アシスタント（Ctrl Shift U）がインターネットを使えるようになり、調べた内容を出典付きで答えます。

  1. Tavily を開き、アカウントを作ります。
  2. キー（tvly- で始まります）はダッシュボードにすでに表示されています。
  3. コピーしてアプリに貼り付けます。
app.tavily.com を開く 無料プラン：月 1,000 クレジット、カード不要。

アプリにキーを貼り付ける

  • 初回は、設定ウィザードがキーを尋ねます。その後は設定 → プロバイダーにあります。
  • テストをクリックします。うまくいかないときは、「不明なエラー」ではなく、プロバイダーからの実際のメッセージが表示されます。
  • プロバイダーの並び順が試す順番です。ドラッグで並べ替えられます。

キーの保存場所

Windows 資格情報マネージャーです。資格情報ストアが使えない、または長すぎるキーを受け付けないというまれな場合にだけ、ユーザーフォルダー内のローカルファイルに保存されます。キーが PC の外に出るのは、リクエストのたびにそのプロバイダーへ送るときだけです。

複数のキー

同じプロバイダーに複数のキーを登録できます。1 つが上限に達したり失敗したりすると、FlowVoice が自動で次のキーに切り替えます。

モデルが廃止されたら？

プロバイダーはよくモデルを入れ替えます。FlowVoice はモデルが使えなくなったことに気づくと、プロバイダーの現在のリストから代わりを選んでテストし、自動で切り替えます。この確認は 1 日 1 回、バックグラウンドでも行います。操作は何も要りません。

無料プランの上限を正直に

どの無料プランにも上限があります。1 分あたりのリクエスト数、1 日あたりの音声の分数などです。日々の音声入力なら十分足ります。正確な数字はときどき変わるので、各プロバイダーのページで確認してください。

各プロバイダーの無料枠の数え方
プロバイダー上限の対象同じアカウントで別のキー
Groqアカウント（組織）全体枠は増えない
Geminiキーではなく Google のプロジェクト同じプロジェクトなら増えない
OpenRouter:free モデルの 1 日あたりのリクエスト数。購入したクレジットがあると増える増えない
Tavily月ごとのクレジット。1 回の検索で 1〜2 消費増えない

同じアカウントのキーを増やしても枠は増えませんGroq では上限がアカウント全体にかかるため、同じアカウントのキーを 5 つ作っても、1 つのときとまったく同じ枠です。本当に役立つのは、Groq と Gemini のように別のプロバイダーを予備に持つことです。

インターネットなし：100% オフライン

クラウドを一切使いたくない？設定 → 文字起こしで100% ローカルを選び、音声認識モデル（Whisper）をダウンロードしてください。文字起こしはプロセッサー上で動き、音声が PC の外に出ることはありません。

アプリには、話す言語に合うおすすめのモデルが表示されます。下の数字はおおよその目安です：

オフラインモデル：サイズ、メモリ、用途
モデルダウンロード使用メモリ向いている用途
Tiny31 MB~150 MBかなり非力な PC 向け。誤りが多め
Base57 MB~300 MB速い。ライブプレビューにも使用
Small181 MB~600 MB主要な言語でバランスが良い
Distil-Whisper pt-BR pt-BR513 MB~950 MBブラジル・ポルトガル語向けに調整
Large v3 Turbo547 MB~1 GBどの言語でも最高の精度
  • 正直なところ：オフラインはクラウドより遅く、控えめな PC で大きなモデルを使うと特にそうです。ローカルモードには AVX2 対応のプロセッサーが必要です（ここ 10 年のものならほとんど対応しています。非対応ならアプリが知らせます）。
  • モデルがメモリを使うのは音声入力の間だけで、数秒後には解放されます。
  • 各モデルは必要なときに一度だけダウンロードされ、同じ画面でいつでも削除できます。
  • 文章の整形もオフラインで行うなら、PC 上で文章 AI を動かせる Ollama を使ってください。

キーは手に入りましたか？あとは話すだけです。
