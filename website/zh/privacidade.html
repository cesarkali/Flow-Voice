摘要

音频只在内存中
录音不会保存到磁盘。音频只发送给你选择的服务商，离线模式下则哪里都不发送。如果转写失败，录音会留在内存中，仅供你重试。
密钥在系统凭据库中
保存在 Windows 凭据管理器中；只有在极少数情况下才会存到本地文件（见下文）。
历史记录只在你的电脑上
可以随时关闭或删除。
零遥测
应用没有统计分析、跟踪或使用情况报告。

你的声音和文字

你听写时，麦克风音频只存在于程序的内存中。它从不写入文件，听写结束后即被丢弃。

唯一的例外：如果转写失败（没网、套餐额度用完、密钥无效），录音会留在内存中供重试按钮使用，最多保留最近 3 次失败。它同样不会写入磁盘：当你删除该条历史记录、清空历史记录或关闭 FlowVoice 时就会消失。

云端

如果你使用云端服务商（Groq、Google Gemini、Mistral、OpenAI、OpenRouter 或自定义地址），FlowVoice 会用你的密钥把以下内容直接发送给它：

  • 音频，用于转成文字；
  • 转写出的文字，以及所选风格的指令、你的词汇和你正在听写的应用名称（让文字语气得当）；
  • 在命令模式下，你选中的文字；
  • 在语音助手中，你的问题和对话。如果有 Tavily 密钥，问题也会发送给 Tavily 用于网页搜索。

中间没有任何 FlowVoice 服务器。各服务商如何处理这些数据，遵循其自身的政策。

值得注意在 Google Gemini 的免费套餐中，Google 可能会使用你发送的内容来改进其产品。如果你介意，请选择其他服务商或离线模式。

离线

在100% 本地模式下，转写在你的处理器上运行。再用 Ollama 润色文字，你说的任何内容都不会离开你的电脑。

API 密钥

密钥保存在 Windows 凭据管理器中。它们只会在每次请求时发送给对应的服务商，在屏幕上以遮掩形式显示。

罕见的例外：如果凭据库不可用或拒绝过长的密钥，密钥会保存在你用户目录下应用设置文件夹中的一个文件里。

保存在你电脑上的内容

  • 听写的历史记录（文字、风格和目标应用），最多保留最近 300 条。可在设置 → 常规 → 保留历史记录中关闭，也可以在主页逐条删除或全部清空。
  • 设置、风格和词汇。
  • 你下载的离线模型。可随时在模型页面删除。
  • 用于诊断问题的技术日志。它只记录技术事件（时间、错误、响应时长），从不记录你听写的内容。大小限制在约 1 MB（超过后会重新创建），也从不发送到任何地方：只有你自己把它附在错误报告里时，它才会离开电脑。

所有内容都在你的 Windows 用户目录中：

FlowVoice 在 Windows 上存放数据的文件夹
文件夹存放内容
%APPDATA%\br.com.caliberda.flowvoice设置、历史记录和日志
%LOCALAPPDATA%\br.com.caliberda.flowvoice离线模型

要一次删除所有内容，只需删除这些文件夹。

应用的其他连接

除了你配置的服务商，FlowVoice 只会在以下情况访问网络：

  • 在 GitHub 上检查更新。更新均有数字签名。
  • 从 Hugging Face 下载离线模型，仅在你要求时。
  • 在“关于”页面显示作者照片，从 GitHub 获取并保存以便离线使用。
  • 检查服务商的模型列表，以便自动替换已下线的模型。

这些连接都不会传送你的声音、文字或历史记录。

遥测：没有

应用没有统计分析、跟踪、用户标识符，也不会自动发送错误报告。我们不知道有多少人在用，也不知道怎么用。代码是开源的：任何人都可以在 GitHub 仓库中核实。

本网站

本网站是静态网站，托管在 Vercel 上。和任何服务器一样，Vercel 会记录访问的技术数据（如 IP 地址和浏览器），用于提供页面和防止滥用，具体遵循其隐私政策。

本网站没有统计分析、Cookie 或跟踪脚本。文字字体来自 Google Fonts，它会像任何服务器一样收到字体的下载请求。

没有表单、登录或广告。安装程序直接从 GitHub 下载。
