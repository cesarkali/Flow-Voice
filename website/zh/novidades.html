2.2：胶囊想放哪就放哪。

录音时拖动胶囊，或选一个专属位置。听写失败时会出现“重试”按钮，应用现在支持 10 种语言。还有一个快捷键，可以修正任何选中文字的拼写。

版本 2.2Windows 10 和 11自动更新

2.2

2026年11月

校对、可拖动的胶囊、重试和 10 种语言

新的快捷键无需开口，就能修正任何选中文字的拼写。胶囊不再固定在一个位置：录音时可以拖动，也可以选一个专属位置。失败的听写不会再丢失，应用也开始跟随 Windows 的语言。

  • 校对选中内容

    • 校对：在任何应用中选中文字，按 Ctrl Alt J。FlowVoice 只修正拼写、重音和标点，不换词、不改风格，也不用你说话。
    • 如果 AI 改动超出这些，文字会保持原样。如果没有需要修正的地方，就不会粘贴任何内容，文字的格式也保持不变。
    • 它也会以 校对 标签出现在命令卡片、结果和历史记录中。在 AltGr J 会输入字符的键盘上，它默认没有快捷键，你可以另选一个。

  • 移动胶囊

    • 录音时可拖动：点击胶囊，拖到屏幕任意角落，甚至另一台显示器上。在这次听写结束前，它会停在你放下的位置；下一次会回到默认位置。
    • 自定义位置：除了底部和顶部，还可以在屏幕缩略图上拖动胶囊来选择位置，会吸附到角落、边缘和中央。点击测试查看它出现的位置。
    • 使用上次拖动到的位置会沿用你上次放下胶囊的地方。这些都在常规 → 浮动窗口中，也可以在那里关闭拖动。

  • 重试与连续听写

    • 转写失败时（网络、额度、密钥），错误卡片会出现重试按钮，并在屏幕上停留 30 秒。历史记录中也会显示这次失败、原因和同样的按钮。
    • 按原样重做：同一应用、风格和翻译，使用当前的服务商和密钥。录音只保存在内存中（最近 3 次失败），绝不写入磁盘。
    • 在同一个输入框连续听写两次时，如果光标还停在上一次结束的位置，两段之间会加一个空格。在终端中以及日语、中文等不用空格的文字中不会添加。

  • 10 种语言

    • 除了葡萄牙语、英语和西班牙语，界面现在还支持法语、德语、日语、中文、俄语、印地语和孟加拉语，并为每种文字使用合适的 Windows 字体。
    • 新的默认选项自动（Windows）会跟随 Windows 的语言。已经在用的人会保留原来的选择。
    • 托盘菜单、错误信息和内置风格的名称都会跟随界面语言。

  • 不冲突的快捷键

    • 由于 Ctrl Alt V 是 Office 的“选择性粘贴”，新安装时再次粘贴不设快捷键。它仍在托盘菜单中，也可以自己选一个快捷键。
    • 在 AltGr K 会输入字符的键盘上，命令一开始不设快捷键，以免占用这个键，快捷键页面会解释原因。

  • 隐私与麦克风

    • 关于页面新增隐私部分：哪些内容留在电脑上，哪些发送给各服务商，密钥存放在哪里。完整政策在这里。
    • 麦克风错误更清楚了：Windows 阻止麦克风时，应用会告诉你去哪里开启；其他应用独占麦克风时，也会提示。
    • 其他应用占用剪贴板时，会显示专门的提示。

  • 应用内的更新介绍

    • 更新后第一次打开窗口时，会用界面语言展示新内容。完整的记录在 关于 → 更新记录，离线也能查看。

  • 修复

    • 如果应用在电脑静音录音的过程中关闭，声音会一直保持静音。现在下次启动时会恢复。
    • 开机自动启动更可靠：应用还会在任务计划程序中创建一个登录任务，无需管理员权限。在任务管理器中禁用启动项现在也真正有效。
    • 带翻译的命令或“换个版本”不会再返回两个版本，也不会在末尾附加说明。
    • 阿拉伯语、希伯来语、波斯语和乌尔都语文字在浮窗、历史记录和聊天中会以正确的方向显示。

2.1

2026年10月

更稳定的预览和玻璃胶囊

一个词只有在连续两次结果都一致时才会确定。在此之前，它显示得更浅，还可能改变。确定之后不会再倒退。

  • 实时预览

    • 文字不再倒退：每个模型一次只处理一个请求，迟到的响应会被丢弃。
    • 预览不再把之前的文字作为上下文发送（有时会导致内容重复出现）。
    • 节奏遵循 Groq 自己告知的限额，并始终为最终转写留出余量，预览之后不会再紧接着出现“已达上限”。
    • 长句最多 15 秒就会断开：响应更快，免费套餐的秒数也用得更少。
    • 移除了预览中额外的 Gemini 通道（写法与 Whisper 不同，而且更慢）。
    • 用同样的 4 段音频测量：显示为已确定、之后又被替换的文字，从每次听写 2.5–7.5 次降到零，更新约每 1.2–1.5 秒到达一次（之前约 1.7–2.0 秒）。

  • 玻璃胶囊

    • 在常规 → 浮动窗口中：玻璃（透明且模糊，边缘发亮）或半透明（色调更淡），使用 Windows 自带的模糊，由显卡渲染。
    • 像 macOS 27 那样的光影：光泽、斜面边缘、底部的光线和柔和的阴影（创意来自 Thiago Silva）。
    • 需要开启 Windows 的透明效果；关闭透明效果或开启节能模式时，胶囊会显示为实色。

  • 修复

    • 在繁忙的电脑上随 Windows 启动时，窗口有时会显示错误，而不是设置。
    • 更新后，FlowVoice 会自动重新打开并显示窗口。

2.0

2026年10月

为什么要重写

2026 年，1.x 对很多人来说已经无法使用：它推荐的 GitHub Models 停止服务；Groq 上原本免费的模型移出了免费套餐；旧版 Gemini 被关闭。而且 1.x 会隐藏真实错误，看起来就像应用“就是不能用”。

2.0 就是为了不再重蹈覆辙：它会显示服务商返回的真实信息，并自动替换已下线的模型。

有哪些变化

  • 听写

    • 实时预览：边说边出现文字。
    • 新的提示词风格，把口语精简后发给 AI，强度可调。
    • 自然、专业、原始、仅转写，以及你自己的风格。
    • 按应用设置风格：Outlook 总用“专业”，VS Code 总用“提示词”。
    • 去掉口头语（“嗯”“那个”、结巴），并遵循你的词汇。

  • 全新浮窗

    • 得到结果后，一键换成另一种风格或翻译成数十种语言。
    • 替换会撤销上一次粘贴，并粘贴新版本。
    • 跟随鼠标或当前聚焦的窗口，显示在你正在使用的显示器上。
    • Esc 随时取消。

  • 新快捷键

    • 对选中内容执行命令：在任何应用中选中文字，说出要做什么（“更正式一点”“总结成要点”）。
    • 再次粘贴上一次听写到当前聚焦的应用。
    • 语音翻译，以及带网页搜索和来源的语音助手。
    • 按住说话模式（push-to-talk）。

  • 更可靠

    • 在服务商之间、多个密钥之间自动切换；云端出故障时改用本地模型。
    • 已下线的模型会自动替换，每天检查一次。
    • 安全粘贴：确认目标窗口，并恢复剪贴板中原有的内容。
    • 麦克风断开时会提示，并改用其他麦克风。

  • 更好的离线体验

    • 按语言分类的模型目录，并为你的语言给出推荐。
    • 针对巴西葡萄牙语优化的模型（Distil-Whisper pt-BR）。
    • 本地转写速度提升数倍。
    • 停止听写后模型会从内存中释放；可随时删除模型。

  • 界面

    • 重新设计的设置界面，带搜索（Ctrl K）。
    • 首次运行向导，附带教程和每个密钥的测试。
    • 浅色和深色主题，自选强调色，PT/EN/ES。
    • 新图标和可搜索的历史记录。
