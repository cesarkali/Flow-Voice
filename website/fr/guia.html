Clés gratuites en quelques minutes

FlowVoice ne coûte rien et n'a pas de serveur propre : il parle directement au fournisseur d'IA que vous choisissez. Il suffit pour cela d'une clé d'API gratuite. Ou d'aucune, si vous préférez travailler hors ligne.

Le chemin le plus rapide

Si vous voulez juste dicter aujourd'hui : créez une clé chez Groq et c'est tout. Il transcrit la voix et affine le texte, il est très rapide, et l'offre gratuite suffit pour une journée entière d'usage normal.

Les autres clés sont facultatives. Avoir plusieurs fournisseurs sert de secours : si l'un échoue ou atteint sa limite, FlowVoice passe tout seul au suivant.

Pas besoin de retenir quoi que ce soitDans l'application, chaque fournisseur a ce même pas-à-pas, un bouton qui ouvre la bonne page et un bouton Tester qui confirme que la clé fonctionne.

Fournisseurs, pas à pas

Chacun prend quelques minutes. Commencez par Groq ; les autres servent de secours ou ajoutent des fonctions.

Groq

RecommandéGratuit

Voix et texte. Transcription et affinage très rapides.

  1. Ouvrez la console Groq et connectez-vous avec Google, GitHub ou une adresse e-mail.
  2. Dans API Keys, cliquez sur Create API Key et donnez-lui un nom quelconque, comme « FlowVoice ».
  3. Copiez la clé (elle commence par gsk_). Elle ne s'affiche qu'une fois.
  4. Collez-la dans FlowVoice et cliquez sur Tester.
Ouvrir console.groq.com Offre gratuite : des heures d'audio par jour, sans carte bancaire.

Google Gemini

Gratuit

Voix et texte. L'IA de Google, avec une offre gratuite généreuse.

  1. Ouvrez Google AI Studio et connectez-vous avec votre compte Google.
  2. Cliquez sur Create API key.
  3. Choisissez un projet existant ou créez-en un nouveau.
  4. Copiez la clé (elle commence par AIza) et collez-la dans l'application.
Ouvrir aistudio.google.com Avec l'offre gratuite, Google peut utiliser ce que vous envoyez pour améliorer ses produits.

OpenRouter

Modèles :free

Texte uniquement : affinage, traduction et questions. Donne accès à des dizaines de modèles, et ceux qui finissent par :free ne coûtent rien.

  1. Ouvrez OpenRouter et connectez-vous avec Google, GitHub ou une adresse e-mail.
  2. Cliquez sur Create Key et donnez-lui un nom. La limite de crédit est facultative.
  3. Copiez la clé (elle commence par sk-or-) et collez-la dans l'application.
Ouvrir openrouter.ai Sans crédit sur le compte : environ 50 requêtes par jour sur les modèles gratuits.

Mistral

Sans carte bancaire

Voix et texte. IA européenne, avec un très bon modèle de transcription.

  1. Ouvrez la console Mistral et créez votre compte.
  2. Choisissez l'offre gratuite (Experiment). Elle ne demande pas de carte bancaire.
  3. Dans API Keys, créez une nouvelle clé.
  4. Copiez la clé et collez-la dans l'application.
Ouvrir console.mistral.ai

Tavily

Recherche web

Facultatif. Donne à l'assistant vocal (Ctrl Shift U) un accès à internet : il cherche et répond en citant ses sources.

  1. Ouvrez Tavily et créez votre compte.
  2. La clé (elle commence par tvly-) s'affiche déjà dans le tableau de bord.
  3. Copiez-la et collez-la dans l'application.
Ouvrir app.tavily.com Offre gratuite : 1 000 crédits par mois, sans carte bancaire.

Coller la clé dans l'application

  • La première fois, l'assistant de configuration demande la clé. Ensuite, elle se trouve dans Paramètres → Fournisseurs.
  • Cliquez sur Tester. Si quelque chose ne va pas, l'application affiche le vrai message du fournisseur, plutôt qu'une « erreur inconnue ».
  • L'ordre des fournisseurs est l'ordre dans lequel ils sont essayés. Faites glisser pour le changer.

Où la clé est conservée

Dans le Gestionnaire d'informations d'identification de Windows. Dans de rares cas seulement, quand le coffre est indisponible ou refuse une clé très longue, elle est placée dans un fichier local de votre dossier utilisateur. Elle ne quitte votre PC que pour aller chez le fournisseur lui-même, à chaque requête.

Plus d'une clé

Vous pouvez enregistrer plusieurs clés pour un même fournisseur. Quand l'une atteint sa limite ou échoue, FlowVoice passe automatiquement à la suivante.

Et quand un modèle est retiré ?

Les fournisseurs changent souvent de modèle. FlowVoice s'aperçoit quand un modèle disparaît, choisit un remplaçant dans la liste actuelle du fournisseur, le teste et se met à l'utiliser tout seul. Il le vérifie aussi une fois par jour, en arrière-plan. Vous n'avez rien à faire.

Limites de l'offre gratuite, sans détour

Toute offre gratuite a un plafond : tant de requêtes par minute, tant de minutes d'audio par jour. Pour la dictée de tous les jours, c'est largement suffisant. Les chiffres exacts changent de temps en temps, alors consultez la page de chaque fournisseur.

Comment la limite gratuite de chaque fournisseur est comptée
FournisseurLa limite s'applique àUne autre clé sur le même compte
GroqLe compte (organisation) entierN'augmente pas le quota
GeminiLe projet Google, pas la cléN'augmente pas, si c'est le même projet
OpenRouterRequêtes par jour sur les modèles :free ; augmente si le compte a des crédits achetésN'augmente pas
TavilyCrédits par mois ; chaque recherche en consomme 1 ou 2N'augmente pas

Plusieurs clés d'un même compte ne s'additionnent pasChez Groq, la limite s'applique au compte entier : cinq clés sur le même compte donnent exactement le même quota qu'une seule. Ce qui aide vraiment, c'est d'avoir des fournisseurs différents en secours, par exemple Groq et Gemini.

Sans internet : 100 % hors ligne

Vous préférez n'utiliser aucun cloud ? Dans Paramètres → Transcription, choisissez 100 % local et téléchargez un modèle de reconnaissance vocale (Whisper). La transcription s'exécute sur votre processeur et l'audio ne quitte jamais le PC.

L'application indique les modèles recommandés pour la langue que vous parlez. Les chiffres ci-dessous sont approximatifs :

Modèles hors ligne : taille, mémoire et usage conseillé
ModèleTéléchargementMémoire utiliséePour qui
Tiny31 MB~150 MBPC très modestes ; se trompe davantage
Base57 MB~300 MBRapide ; aussi utilisé pour l'aperçu en direct
Small181 MB~600 MBBon équilibre pour les langues les plus parlées
Distil-Whisper pt-BR pt-BR513 MB~950 MBOptimisé pour le portugais du Brésil
Large v3 Turbo547 MB~1 GBPrécision maximale dans n'importe quelle langue
  • Soyons honnêtes : le hors ligne est plus lent que le cloud, surtout avec les gros modèles sur des PC modestes. Le mode local demande un processeur compatible AVX2 (la plupart de ceux des dix dernières années le sont ; si le vôtre ne l'est pas, l'application vous prévient).
  • Le modèle n'occupe la mémoire que pendant que vous dictez et est libéré quelques secondes après.
  • Chaque modèle est téléchargé une seule fois, uniquement quand vous le demandez, et peut être supprimé à tout moment sur le même écran.
  • Pour affiner le texte aussi sans internet, utilisez Ollama, qui exécute une IA de texte sur votre PC.

Vous avez la clé ? Il ne reste qu'à parler.
