Your voice is yours.

FlowVoice has no server, asks for no account and collects nothing about you. This page explains, without legalese, where everything goes.

Summary

Audio stays in memory
No recording is saved to disk. The audio goes only to the provider you chose, or nowhere in offline mode. If transcription fails, the recording stays in memory only so you can try again.
Keys in the system vault
Kept in the Windows Credential Manager; only in rare cases are they stored in a local file (see below).
History only on your PC
Can be turned off or deleted whenever you want.
Zero telemetry
The app has no analytics, tracking or usage reports.

Your voice and your text

While you dictate, the microphone audio stays only in the program's memory. It is never written to a file and is discarded when the dictation ends.

The only exception: if transcription fails (no internet, plan limit, invalid key), the recording stays in memory for the Try again button, at most the last 3 failures. It also never goes to disk: it disappears when you delete the history item, clear the history or close FlowVoice.

In the cloud

If you use a cloud provider (Groq, Google Gemini, Mistral, OpenAI, OpenRouter or an address of your own), FlowVoice sends directly to it, with your key:

  • the audio, to be turned into text;
  • the transcribed text, along with the instructions of the chosen style, your vocabulary and the name of the application you are dictating in (so the text comes out in the right tone);
  • in Command mode, the text you selected;
  • in the voice assistant, the question and the conversation. With a Tavily key, the question also goes to Tavily, to search the web.

There is no FlowVoice server in the middle. What each provider does with this data follows its own policy.

Good to knowOn Google Gemini's free plan, Google may use what you send to improve its products. If that bothers you, prefer another provider or offline mode.

Offline

In 100% local mode, transcription runs on your processor. With Ollama polishing the text, nothing you say leaves your computer.

API keys

Keys stay in the Windows Credential Manager. They only leave the PC to go to the provider itself, with each request, and appear masked on screen.

Rare exception: if the vault is unavailable or rejects a key that is too long, it is stored in a file inside the app's settings folder, in your user profile.

What is saved on your PC

  • History of dictations (text, style and target app), up to the 300 most recent. Turn it off in Settings → General → Keep history, delete items one by one or clear everything on the Home screen.
  • Settings, styles and vocabulary.
  • Offline models you downloaded. Delete them whenever you want on the models screen.
  • A technical log to diagnose problems. It records only technical events (times, errors, response times), never what you dictated. It is limited to about 1 MB (it is recreated when it goes over) and is never sent anywhere: it only leaves the PC if you attach it to a bug report yourself.

Everything stays inside your Windows user profile:

Folders where FlowVoice stores data on Windows
FolderWhat it stores
%APPDATA%\br.com.caliberda.flowvoiceSettings, history and log
%LOCALAPPDATA%\br.com.caliberda.flowvoiceOffline models

To delete everything at once, just delete these folders.

Other connections the app makes

Besides the providers you configured, FlowVoice only goes online to:

  • Check for updates on GitHub. Updates are digitally signed.
  • Download offline models from Hugging Face, only when you ask.
  • Show the author's photo on the About screen, fetched from GitHub and kept for offline use.
  • Check the model list of your providers, to automatically swap a retired model.

None of these connections carries your voice, your text or your history.

Telemetry: none

The app has no analytics, tracking, user identifier or automatic error reporting. We don't know how many people use it, or how. The code is open: anyone can check it in the GitHub repository.

This site

This site is static and hosted on Vercel. Like any server, Vercel logs technical data about visits (such as IP address and browser) to deliver the pages and protect against abuse, according to its privacy policy.

The site has no analytics, cookies or tracking scripts. The text font comes from Google Fonts, which receives the request to download it like any server.

There are no forms, logins or ads. The installer is downloaded directly from GitHub.

Contact
