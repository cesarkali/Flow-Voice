ডাউনলোড

বিনামূল্যের কী, মাত্র কয়েক মিনিটে

FlowVoice কোনো টাকা নেয় না এবং এর নিজস্ব কোনো সার্ভার নেই: এটি সরাসরি আপনার বেছে নেওয়া AI প্রদানকারীর সঙ্গে কথা বলে। এর জন্য একটি বিনামূল্যের API কী-ই যথেষ্ট। অথবা একটিও না, যদি অফলাইনে ব্যবহার করতে চান।

বিনামূল্যের প্ল্যানে কার্ড লাগে নাকী থাকে Windows-এর ভল্টেঅফলাইনেও চলে

  2. প্রদানকারী, ধাপে ধাপে

সবচেয়ে দ্রুত পথ

আজই শুধু ডিকটেট করতে চাইলে: Groq-এ একটি কী তৈরি করুন, ব্যস। এটি কণ্ঠ ট্রান্সক্রাইব করে এবং লেখা গুছিয়ে দেয়, খুব দ্রুত, আর বিনামূল্যের প্ল্যানে সারাদিনের স্বাভাবিক ব্যবহার চলে যায়।

বাকি কী ঐচ্ছিক। একাধিক প্রদানকারী ব্যাকআপ হিসেবে কাজ করে: একটি ব্যর্থ হলে বা সীমায় পৌঁছালে FlowVoice নিজে থেকেই পরেরটিতে চলে যায়।

কিছু মুখস্থ করতে হবে নাঅ্যাপের ভেতরে প্রতিটি প্রদানকারীর জন্য এই একই ধাপগুলো আছে, সঠিক পেজ খোলার একটি বোতাম, আর একটি পরীক্ষা করুন বোতাম, যা নিশ্চিত করে কী কাজ করছে কি না।

প্রদানকারী, ধাপে ধাপে

প্রতিটিতে কয়েক মিনিট লাগে। Groq দিয়ে শুরু করুন; বাকিগুলো ব্যাকআপ হিসেবে কাজ করে বা নতুন সুবিধা যোগ করে।

Groq

প্রস্তাবিতবিনামূল্যে

কণ্ঠ ও লেখা। খুব দ্রুত ট্রান্সক্রিপশন ও গোছানো।

  1. Groq কনসোল খুলুন এবং Google, GitHub বা ইমেল দিয়ে সাইন ইন করুন।
  2. API Keys-এ গিয়ে Create API Key-এ ক্লিক করুন এবং যেকোনো একটি নাম দিন, যেমন “FlowVoice”।
  3. কী কপি করুন (শুরু হয় gsk_ দিয়ে)। এটি একবারই দেখা যায়।
  4. FlowVoice-এ পেস্ট করে পরীক্ষা করুন-এ ক্লিক করুন।
console.groq.com খুলুন বিনামূল্যের প্ল্যান: দিনে কয়েক ঘণ্টার অডিও, কার্ড ছাড়া।

Google Gemini

বিনামূল্যে

কণ্ঠ ও লেখা। Google-এর AI, উদার বিনামূল্যের প্ল্যানসহ।

  1. Google AI Studio খুলুন এবং আপনার Google অ্যাকাউন্ট দিয়ে সাইন ইন করুন।
  2. Create API key-এ ক্লিক করুন।
  3. একটি বিদ্যমান প্রজেক্ট বেছে নিন বা নতুন একটি তৈরি করুন।
  4. কী কপি করুন (শুরু হয় AIza দিয়ে) এবং অ্যাপে পেস্ট করুন।
aistudio.google.com খুলুন বিনামূল্যের প্ল্যানে Google আপনার পাঠানো ডেটা ব্যবহার করতে পারে নিজেদের পণ্য উন্নত করতে।

OpenRouter

মডেল :free

শুধু লেখা: গোছানো, অনুবাদ আর প্রশ্ন। কয়েক ডজন মডেলে প্রবেশাধিকার দেয়, আর যেগুলোর নাম :free দিয়ে শেষ, সেগুলোর কোনো খরচ নেই।

  1. OpenRouter খুলুন এবং Google, GitHub বা ইমেল দিয়ে সাইন ইন করুন।
  2. Create Key-এ ক্লিক করে একটি নাম দিন। ক্রেডিট সীমা ঐচ্ছিক।
  3. কী কপি করুন (শুরু হয় sk-or- দিয়ে) এবং অ্যাপে পেস্ট করুন।
openrouter.ai খুলুন অ্যাকাউন্টে ক্রেডিট না থাকলে: বিনামূল্যের মডেলে দিনে প্রায় ৫০টি অনুরোধ।

Mistral

কার্ড লাগে না

কণ্ঠ ও লেখা। ইউরোপীয় AI, খুব ভালো একটি ট্রান্সক্রিপশন মডেলসহ।

  1. Mistral কনসোল খুলুন এবং আপনার অ্যাকাউন্ট তৈরি করুন।
  2. বিনামূল্যের প্ল্যান (Experiment) বেছে নিন। এতে কার্ড লাগে না।
  3. API Keys-এ একটি নতুন কী তৈরি করুন।
  4. কী কপি করে অ্যাপে পেস্ট করুন।
console.mistral.ai খুলুন

Tavily

ওয়েব সার্চ

ঐচ্ছিক। ভয়েস সহকারীকে (Ctrl Shift U) ইন্টারনেটে প্রবেশাধিকার দেয়: এটি খুঁজে দেখে এবং উৎস উল্লেখ করে উত্তর দেয়।

  1. Tavily খুলুন এবং আপনার অ্যাকাউন্ট তৈরি করুন।
  2. কী (শুরু হয় tvly- দিয়ে) ড্যাশবোর্ডেই দেখা যায়।
  3. কপি করে অ্যাপে পেস্ট করুন।
app.tavily.com খুলুন বিনামূল্যের প্ল্যান: মাসে ১,০০০ ক্রেডিট, কার্ড ছাড়া।

অ্যাপে কী পেস্ট করা

  • প্রথমবার সেটআপ উইজার্ড কী চায়। পরে এটি থাকে সেটিংস → প্রদানকারী-তে।
  • পরীক্ষা করুন-এ ক্লিক করুন। কিছু ভুল হলে অ্যাপ প্রদানকারীর আসল বার্তা দেখায়, “অজানা ত্রুটি” নয়।
  • প্রদানকারীর ক্রমই চেষ্টার ক্রম। বদলাতে টেনে নিন।

কী কোথায় রাখা হয়

Windows ক্রেডেনশিয়াল ম্যানেজারে। শুধু বিরল ক্ষেত্রে, ভল্ট উপলব্ধ না থাকলে বা খুব লম্বা কী নিতে না চাইলে, এটি আপনার ইউজার ফোল্ডারের একটি লোকাল ফাইলে থাকে। এটি আপনার PC ছাড়ে শুধু সংশ্লিষ্ট প্রদানকারীর কাছে, প্রতিটি অনুরোধের সঙ্গে।

একাধিক কী

একই প্রদানকারীতে একাধিক কী যোগ করতে পারেন। একটি সীমায় পৌঁছালে বা ব্যর্থ হলে FlowVoice নিজে থেকেই পরেরটিতে চলে যায়।

আর কোনো মডেল অবসরে গেলে?

প্রদানকারীরা প্রায়ই মডেল বদলায়। FlowVoice বুঝতে পারে কখন কোনো মডেল বন্ধ হয়ে গেছে, প্রদানকারীর বর্তমান তালিকা থেকে বিকল্প বেছে নেয়, পরীক্ষা করে এবং নিজে থেকেই সেটি ব্যবহার শুরু করে। দিনে একবার ব্যাকগ্রাউন্ডে এটি যাচাইও করে। আপনাকে কিছুই করতে হয় না।

বিনামূল্যের প্ল্যানের সীমা, সোজাসুজি

প্রতিটি বিনামূল্যের প্ল্যানের একটি সীমা আছে: মিনিটে এতগুলো অনুরোধ, দিনে এত মিনিট অডিও। রোজকার ডিকটেশনের জন্য তা যথেষ্টর চেয়েও বেশি। সঠিক সংখ্যা মাঝে মাঝে বদলায়, তাই প্রতিটি প্রদানকারীর পেজে দেখে নিন।

প্রতিটি প্রদানকারীর বিনামূল্যের সীমা কীভাবে গোনা হয়
প্রদানকারীসীমা প্রযোজ্যএকই অ্যাকাউন্টে আরেকটি কী
Groqপুরো অ্যাকাউন্ট (সংস্থা)কোটা বাড়ে না
GeminiGoogle প্রজেক্ট, কী নয়একই প্রজেক্টের হলে বাড়ে না
OpenRouter:free মডেলে দিনে অনুরোধ; অ্যাকাউন্টে কেনা ক্রেডিট থাকলে বাড়েবাড়ে না
Tavilyমাসে ক্রেডিট; প্রতিটি সার্চে ১ বা ২টি খরচ হয়বাড়ে না

একই অ্যাকাউন্টের একাধিক কী যোগ হয় নাGroq-এ সীমা পুরো অ্যাকাউন্টের ওপর: একই অ্যাকাউন্টে পাঁচটি কী থাকলেও কোটা ঠিক একটির সমান। আসলে কাজে লাগে ব্যাকআপ হিসেবে ভিন্ন প্রদানকারী, যেমন Groq আর Gemini।

ইন্টারনেট ছাড়া: ১০০% অফলাইন

কোনো ক্লাউডই চান না? সেটিংস → ট্রান্সক্রিপশন-এ ১০০% লোকাল বেছে নিন এবং একটি স্পিচ রিকগনিশন মডেল (Whisper) ডাউনলোড করুন। ট্রান্সক্রিপশন চলে আপনার প্রসেসরে, আর অডিও কখনো PC ছাড়ে না।

আপনি যে ভাষায় কথা বলেন, তার জন্য কোন মডেলগুলো প্রস্তাবিত, অ্যাপ তা দেখায়। নিচের সংখ্যাগুলো আনুমানিক:

Large v3 Turbo547 MB~1 GBযেকোনো ভাষায় সর্বোচ্চ নির্ভুলতা
  • সত্যি বলতে: অফলাইন ক্লাউডের চেয়ে ধীর, বিশেষ করে সাধারণ PC-তে বড় মডেলে। লোকাল মোডে AVX2 সমর্থিত প্রসেসর লাগে (গত দশ বছরের বেশিরভাগ প্রসেসরে আছে; আপনারটায় না থাকলে অ্যাপ জানিয়ে দেয়)।
  • মডেল শুধু ডিকটেশনের সময় মেমরি নেয়, আর কয়েক সেকেন্ড পরেই তা ছেড়ে দেয়।
  • প্রতিটি মডেল একবারই ডাউনলোড হয়, শুধু আপনি চাইলে, আর একই স্ক্রিন থেকে যেকোনো সময় মুছে ফেলা যায়।
  • ইন্টারনেট ছাড়াও লেখা গোছাতে Ollama ব্যবহার করুন, যা আপনার PC-তে একটি টেক্সট AI চালায়।

কী হাতে পেয়েছেন? এবার শুধু বলুন।

হালকা ইনস্টলার, অ্যাডমিন অনুমতি লাগে না।
