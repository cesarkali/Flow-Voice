Бесплатные ключи за пару минут

FlowVoice ничего не стоит и не имеет своего сервера: он общается напрямую с выбранным вами ИИ-провайдером. Для этого достаточно бесплатного API-ключа. Или вообще без ключа, если вы предпочитаете работать офлайн.

Самый быстрый путь

Если хотите начать диктовать уже сегодня: создайте ключ в Groq — и всё. Он распознаёт речь и дорабатывает текст, работает очень быстро, а бесплатного тарифа хватает на целый день обычной работы.

Остальные ключи необязательны. Несколько провайдеров служат резервом: если один откажет или упрётся в лимит, FlowVoice сам перейдёт к следующему.

Запоминать ничего не нужноВ приложении для каждого провайдера есть та же инструкция, кнопка, открывающая нужную страницу, и кнопка Проверить, которая подтверждает, что ключ работает.

Провайдеры, шаг за шагом

Каждый занимает пару минут. Начните с Groq; остальные служат резервом или добавляют возможности.

Groq

РекомендуетсяБесплатно

Голос и текст. Очень быстрые распознавание и доработка.

  1. Откройте консоль Groq и войдите через Google, GitHub или e-mail.
  2. В разделе API Keys нажмите Create API Key и задайте любое имя, например «FlowVoice».
  3. Скопируйте ключ (начинается с gsk_). Он показывается только один раз.
  4. Вставьте его во FlowVoice и нажмите Проверить.
Открыть console.groq.com Бесплатный тариф: часы аудио в день, без карты.

Google Gemini

Бесплатно

Голос и текст. ИИ от Google с щедрым бесплатным тарифом.

  1. Откройте Google AI Studio и войдите в аккаунт Google.
  2. Нажмите Create API key.
  3. Выберите существующий проект или создайте новый.
  4. Скопируйте ключ (начинается с AIza) и вставьте в приложение.
Открыть aistudio.google.com На бесплатном тарифе Google может использовать то, что вы отправляете, для улучшения своих продуктов.

OpenRouter

Модели :free

Только текст: доработка, перевод и вопросы. Открывает доступ к десяткам моделей, а те, что заканчиваются на :free, ничего не стоят.

  1. Откройте OpenRouter и войдите через Google, GitHub или e-mail.
  2. Нажмите Create Key и задайте имя. Лимит кредитов указывать необязательно.
  3. Скопируйте ключ (начинается с sk-or-) и вставьте в приложение.
Открыть openrouter.ai Без кредитов на счёте: около 50 запросов в день к бесплатным моделям.

Mistral

Без карты

Голос и текст. Европейский ИИ с очень хорошей моделью распознавания.

  1. Откройте консоль Mistral и создайте аккаунт.
  2. Выберите бесплатный тариф (Experiment). Карта не нужна.
  3. В разделе API Keys создайте новый ключ.
  4. Скопируйте ключ и вставьте в приложение.
Открыть console.mistral.ai

Tavily

Веб-поиск

Необязательно. Даёт голосовому ассистенту (Ctrl Shift U) доступ в интернет: он ищет и отвечает со ссылками на источники.

  1. Откройте Tavily и создайте аккаунт.
  2. Ключ (начинается с tvly-) уже виден на панели.
  3. Скопируйте и вставьте в приложение.
Открыть app.tavily.com Бесплатный тариф: 1000 кредитов в месяц, без карты.

Вставляем ключ в приложение

  • При первом запуске мастер настройки попросит ключ. Потом он находится в Настройки → Провайдеры.
  • Нажмите Проверить. Если что-то не так, приложение покажет настоящее сообщение провайдера, а не «неизвестную ошибку».
  • Порядок провайдеров — это порядок попыток. Перетаскивайте, чтобы изменить.

Где хранится ключ

В диспетчере учётных данных Windows. Лишь в редких случаях, когда хранилище недоступно или отказывается принять слишком длинный ключ, он сохраняется в локальном файле в вашей папке пользователя. С ПК ключ уходит только к самому провайдеру, при каждом запросе.

Несколько ключей

Можно добавить несколько ключей для одного провайдера. Когда один упирается в лимит или отказывает, FlowVoice автоматически переходит к следующему.

А если модель снимут с поддержки?

Провайдеры часто меняют модели. FlowVoice замечает, когда модель перестаёт работать, выбирает замену из текущего списка провайдера, проверяет её и сам начинает её использовать. Ещё он раз в день проверяет это в фоне. Вам ничего не нужно делать.

Лимиты бесплатных тарифов, без прикрас

У каждого бесплатного тарифа есть потолок: столько-то запросов в минуту, столько-то минут аудио в день. Для повседневной диктовки этого с запасом. Точные цифры время от времени меняются, поэтому сверяйтесь со страницей каждого провайдера.

Как считается бесплатный лимит каждого провайдера
ПровайдерЛимит действует наЕщё один ключ в том же аккаунте
GroqВесь аккаунт (организацию)Квоту не увеличивает
GeminiПроект Google, а не ключНе увеличивает, если из того же проекта
OpenRouterЗапросы в день к моделям :free; больше, если на счёте есть купленные кредитыНе увеличивает
TavilyКредиты в месяц; каждый поиск тратит 1 или 2Не увеличивает

Ключи одного аккаунта не суммируютсяВ Groq лимит действует на весь аккаунт: пять ключей в одном аккаунте дают ровно ту же квоту, что и один. По-настоящему помогает иметь в резерве разных провайдеров, например Groq и Gemini.

Без интернета: 100% офлайн

Не хотите никаких облаков? В Настройки → Распознавание выберите 100% локально и скачайте модель распознавания речи (Whisper). Распознавание идёт на вашем процессоре, и аудио никогда не покидает ПК.

Приложение показывает, какие модели рекомендуются для языка, на котором вы говорите. Цифры ниже приблизительные:

Офлайн-модели: размер, память и для чего подходят
МодельЗагрузкаПамятьДля кого
Tiny31 MB~150 MBСовсем слабые ПК; ошибается чаще
Base57 MB~300 MBБыстрая; также используется в предпросмотре
Small181 MB~600 MBХороший баланс для самых распространённых языков
Distil-Whisper pt-BR pt-BR513 MB~950 MBНастроена на бразильский португальский
Large v3 Turbo547 MB~1 GBМаксимальная точность на любом языке
  • Честно говоря: офлайн медленнее облака, особенно с большими моделями на скромных ПК. Локальному режиму нужен процессор с AVX2 (он есть у большинства за последние десять лет; если у вашего нет, приложение предупредит).
  • Модель занимает память, только пока вы диктуете, и освобождает её через несколько секунд.
  • Каждая модель скачивается один раз, только по вашему запросу, и её можно удалить в любой момент на том же экране.
  • Чтобы и дорабатывать текст без интернета, используйте Ollama — он запускает текстовый ИИ на вашем ПК.
