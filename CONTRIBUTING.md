# Como contribuir

O FlowVoice é mantido por uma pessoa e **não aceita pull requests**. O código está aberto para quem quiser ler, auditar e compilar.

Do que mais ajuda:

- **Achou um problema?** Abra uma [issue de problema](https://github.com/cesarkali/Flow-Voice/issues/new?template=bug_report.yml). No app, **Sobre → Reportar um problema** já preenche as versões e pode anexar um trecho limpo do log.
- **Tem uma ideia?** Abra uma [sugestão de melhoria](https://github.com/cesarkali/Flow-Voice/issues/new?template=feature_request.yml).
- **Falha de segurança?** Não abra issue: veja o [SECURITY.md](SECURITY.md).
- **Quer apoiar?** Pix ou GitHub Sponsors, os links estão no [README](README.md#apoie-o-projeto).
